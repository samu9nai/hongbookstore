# 결정 기록

이 문서는 홍책방의 정책·방향 결정을 기록한다. 에이전트는 **미결정 항목을 임의로 정하지 않는다.**
미결정 항목에 걸리는 작업을 만나면 구현을 멈추고 사용자에게 선택지를 제시한다.

## 기록 방법

- 사용자가 결정하면 항목을 "결정됨"으로 옮기고 날짜·결정·이유를 적는다.
- 결정을 뒤집을 때는 기존 항목을 지우지 않고 "대체됨: D-xx"를 적은 뒤 새 항목을 추가한다.
- 에이전트의 제안은 "제안" 칸에 적는다. 제안은 결정이 아니다.
